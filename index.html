v3.34 reading safeguards

  1. Every PDF page is extracted separately.
  2. Page number is stored with each text block.
  3. PDF line-break and spacing noise is normalised without changing wording.
  4. Search ranks exact phrases, words and numeric matches.
  5. Top evidence is displayed for checking.
  6. If no supporting evidence exists, the app says “Not found in supplied material.”
